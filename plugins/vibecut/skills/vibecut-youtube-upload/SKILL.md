# vibecut-youtube-upload 스킬

```
영상.mp4 + youtube_description.txt + thumbnail.png
   ├─ [1] 파일 확인 + 제목 고르기 + 메타데이터 검증   (youtube_meta.py)
   ├─ [2] 올리기 전 요약을 보여주고 확인받기
   ├─ [3] YouTube 스튜디오(Aside 브라우저)에 업로드 → 비공개로 저장
   └─ [4] 영상 링크 전달 → 사용자가 "공개해줘"라고 하면 그때 공개/예약
```

## 지켜야 할 것

- **공개·예약 게시는 사용자가 그 말을 했을 때만 한다.** 기본 공개 범위는 항상 **비공개**다.
  업로드는 되돌릴 수 있지만 공개는 시청자에게 바로 나간다.
- **로그인·본인 인증·2단계 인증은 사용자가 직접 한다.** 비밀번호나 인증 코드를 대신 입력하지 않는다.
  화면에 "본인 인증", 로그인, "동영상 업로드를 확인하세요" 같은 창이 뜨면 멈추고 사용자에게 알린다.
- **같은 영상을 두 번 올리지 않는다.** 중간에 실패하면 다시 올리기 전에 스튜디오 "콘텐츠" 목록에
  이미 올라간(비공개/초안) 같은 제목의 영상이 있는지 먼저 본다.
- 브라우저는 `aside repl`을 쓴다(전역 규칙). 시작 전에 아래 두 가지를 읽는다.
  ```bash
  aside guide repl
  aside skills show google-accounts      # 구글 서비스를 만지기 전에 읽으라고 되어 있다
  ```
  Aside의 `youtube` 스킬은 검색·자막·댓글 읽기 전용이라 업로드에는 쓸 수 없다.
- REPL은 호출마다 새로 시작하고(`page`가 비어 있다) 120초 제한이 있다. 호출마다 `openTab()`부터 시작하고,
  업로드 대기는 여러 번에 나눠 확인한다.

## 1단계: 파일과 메타데이터

필요한 것:

| 항목 | 찾는 곳 | 없으면 |
|---|---|---|
| 영상 mp4 | 사용자가 준 경로. CapCut에서 내보낸 파일 | 묻는다 (CapCut 프로젝트 파일은 올릴 수 없다) |
| `youtube_description.txt` | 영상과 같은 폴더 | vibecut-youtube-description 스킬을 먼저 실행하자고 안내 |
| 썸네일 png/jpg | 영상 폴더의 `thumbnail.png`, 없으면 `thumbnail/` | 없이 올릴지 묻는다 |

```bash
SCRIPTS=$(python3 -c "import json,os; print(json.load(open(os.path.expanduser('~/.vibecut/config.json'))).get('scripts_dir',''))")
ffprobe -v error -show_entries format=duration,size -of default=nw=1 "<영상.mp4>"
uv run "${SCRIPTS}/youtube_meta.py" "<youtube_description.txt>"            # 제목 후보 A/B/C를 본다
uv run "${SCRIPTS}/youtube_meta.py" "<youtube_description.txt>" --title A  # 고른 뒤 검증 (problems가 있으면 종료 코드 1)
```

- 제목은 후보를 **AskUserQuestion**으로 고르게 한다. 직접 쓴 제목도 받는다.
- `problems`(제목 100자 초과, 설명 5,000자 초과, `<` `>` 포함, 챕터가 00:00으로 시작하지 않음/3개 미만/10초 미만 간격)는
  올리기 전에 고친다. 설명을 고치면 사용자에게 바뀐 부분을 보여 준다.
- 파일 크기가 크면(수 GB) 업로드에 시간이 걸린다고 먼저 말한다.

## 2단계: 올리기 전 확인

아래를 한 번에 보여 주고 "이대로 비공개로 올릴까요?"를 묻는다.

```
영상: <경로> (<길이>, <크기>)
제목: <제목>
설명: 첫 3줄 + 챕터 N개 + 총 N자
썸네일: <경로 또는 없음>
공개 범위: 비공개   시청자층: 아동용 아님
채널: <스튜디오에 로그인된 채널 이름>   ← 3단계에서 확인한 값
```

## 3단계: 스튜디오에 올리기

화면 문구는 한국어 UI 기준이다. **ref 번호를 외우지 말고** 매번 `snapshot()`으로 보고 `getByRole`로 찾는다.

1. 채널 확인
   ```js
   const p = await openTab('https://studio.youtube.com');
   await sleep(5000);
   const s = await snapshot(p, { interactive: true });
   console.log(s.tree);   // 채널 이름·로그인 상태 확인. 채널이 여러 개면 사용자에게 어느 채널인지 묻는다
   ```
2. 업로드 창 열기: `만들기` → `동영상 업로드`
   ```js
   await p.getByRole('button', { name: '만들기' }).click();
   await p.getByRole('menuitem', { name: '동영상 업로드' }).click();
   ```
   - 이때 **"본인 인증" 창**이 뜰 수 있다(2026-10-22 실측). `다음`을 눌러 진행하는 것은 사용자의 휴대전화 인증이 필요하므로
     누르지 말고 사용자에게 직접 하도록 안내한 뒤, 끝났다고 하면 이어간다.
3. 파일 선택: 업로드 창의 숨은 `input[type=file]`에 파일을 넣는다.
   ```js
   await p.locator('input[type="file"]').first().setInputFiles('<영상.mp4 절대경로>');
   ```
   (Aside `locator.setInputFiles`가 있는 것은 확인했지만, 실제 업로드까지는 이 스킬을 처음 쓸 때 검증한다.
   파일 선택 창이 뜨면 `p.waitForEvent('filechooser')` 방식으로 바꾼다.)
4. "세부정보" 단계 채우기 — 제목, 설명은 입력칸을 비운 뒤 **전체 선택 → 붙여넣기 수준으로** 한 번에 넣는다
   (`fill`로 줄바꿈이 있는 긴 설명이 그대로 들어갔는지 스냅샷으로 확인한다).
   - 제목(필수): 입력칸은 기본으로 파일 이름이 들어 있다. 반드시 지우고 새로 넣는다.
   - 설명: 챕터 줄(`00:00 …`)이 줄바꿈 그대로 들어갔는지 확인한다.
   - 썸네일: "썸네일 업로드"의 파일 입력에 `setInputFiles`. 맞춤 썸네일은 **채널 인증(휴대전화)** 이 된 채널만 쓸 수 있다.
     막혀 있으면 썸네일 없이 올리고, 나중에 직접 올리도록 안내한다.
   - 시청자층(필수): `아니요, 아동용이 아닙니다`.
   - (선택) 재생목록, 더보기의 태그·카테고리·언어는 사용자가 정해 준 것만 넣는다.
5. `다음`을 눌러 "동영상 요소"(자막·카드·최종 화면)는 건너뛰고, "검토" 단계(저작권 검사)까지 진행한다.
   검사 결과가 "문제 없음"이면 계속, 문제가 나오면 내용을 사용자에게 그대로 알린다.
6. "공개 상태"에서 **`비공개`** 를 고르고 `저장`. 업로드·처리 중에는 탭을 닫지 않는다.
   진행률은 30초 간격으로 스냅샷을 찍어 확인한다(한 REPL 호출에 오래 두지 않는다).
7. 끝나면 영상 링크(`https://youtu.be/…`)를 읽어 사용자에게 준다. 스튜디오 "콘텐츠" 목록에 비공개로 보이는지 확인한다.

## 4단계: 공개·예약 (사용자가 요청했을 때만)

- "공개해줘": 영상 세부정보 → `공개 상태` → `공개` → `저장`.
- "OO일 OO시에 예약": `예약`을 고르고 날짜·시각을 넣는다(시간대는 스튜디오에 표시된 것을 그대로 읽어 사용자에게 확인).
- 공개 직전에 한 번 더 제목·썸네일·설명 첫 줄을 보여 주고 확인받는다.
- 공개한 뒤에는 시청 페이지(`https://youtu.be/…`)를 열어 제목·썸네일·챕터가 보이는지 확인하고 결과를 알린다.

## 자주 막히는 곳

| 증상 | 원인·처리 |
|---|---|
| "본인 인증" 창 | 사용자가 직접 인증. 대신 누르지 않는다 |
| 맞춤 썸네일 버튼이 비활성 | 채널 휴대전화 인증 필요. 썸네일 없이 올리고 안내 |
| 챕터가 영상에 안 나옴 | 첫 챕터가 `00:00`이 아니거나 3개 미만/10초 미만. `youtube_meta.py`가 미리 잡는다 |
| 일일 업로드 한도 | 스튜디오 문구를 그대로 전달하고 중단 |
| 처리 중 "HD 처리 중" | 정상. 비공개 저장은 이 단계가 끝나기 전에도 가능 |
| REPL 120초 초과 | 호출을 나눈다. 업로드 자체는 브라우저에서 계속 진행된다 |

## 사용 예시

| 사용자 발화 | 동작 |
|---|---|
| "이 영상 유튜브에 올려줘" | 1~3단계, 비공개로 저장 후 링크 전달 |
| "방금 올린 거 공개해줘" | 4단계(확인 후 공개) |
| "내일 저녁 7시에 예약해줘" | 4단계(예약) |
| "제목만 B로 바꿔줘" | 스튜디오 세부정보에서 제목만 수정 후 저장 |
